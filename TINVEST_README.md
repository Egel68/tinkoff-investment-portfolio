# Экспорт портфеля Т-Инвестиций в Excel

Скрипт для автоматического формирования отчёта о портфеле Т-Инвестиций в формате Excel.

## Возможности

- 🔄 Автоматическое получение данных по всем счетам
- 📊 Создание отдельных листов для каждого счёта
- 📈 Расчёт долей ценных бумаг:
  - Доля бумаги от суммы счёта
  - Доля бумаги от общего капитала
- 💰 Отображение средней стоимости покупки и рыночной стоимости
- 📋 Сводный лист с общей информацией

## Установка

### 1. Установите Python 3.8+

Убедитесь, что у вас установлен Python 3.8 или выше:

```bash
python --version
```

### 2. Создайте виртуальное окружение (рекомендуется)

```bash
python -m venv tinvest_venv

# Linux/macOS
source tinvest_venv/bin/activate

# Windows
tinvest_venv\Scripts\activate
```

### 3. Установите зависимости

```bash
# Установка SDK Т-Инвестиций
pip install t-tech-investments --index-url https://opensource.tbank.ru/api/v4/projects/238/packages/pypi/simple

# Установка openpyxl для работы с Excel
pip install openpyxl
```

## Получение токена

1. Войдите в приложение Т-Инвестиции или на сайт [Т-Банк](https://www.tbank.ru/)
2. Перейдите в раздел "Настройки" → "Инвестиции"
3. Найдите раздел "API" или "Токены для доступа"
4. Создайте новый токен с правами:
   - **Чтение портфеля** (обязательно)
   - **Получение рыночных данных** (обязательно)
5. Скопируйте токен и сохраните его в безопасном месте

⚠️ **Важно**: Никогда не передавайте свой токен третьим лицам!

## Использование

### Базовый запуск

```bash
python tinvest_portfolio.py --token ВАШ_ТОКЕН
```

### Указание имени файла

```bash
python tinvest_portfolio.py --token ВАШ_ТОКЕН --output my_portfolio.xlsx
```

### Через переменную окружения

```bash
# Linux/macOS
export TINVEST_TOKEN=ВАШ_ТОКЕН
python tinvest_portfolio.py

# Windows (PowerShell)
$env:TINVEST_TOKEN="ВАШ_ТОКЕН"
python tinvest_portfolio.py

# Windows (CMD)
set TINVEST_TOKEN=ВАШ_ТОКЕН
python tinvest_portfolio.py
```

## Структура Excel файла

### Лист "Сводка"

Общая информация по всем счетам:
| Счёт | ID | Тип | Стоимость, руб. | Доля от капитала, % |
|------|-----|-----|-----------------|---------------------|
| Основной | xxx-xxx | Брокерский | 500 000,00 | 50% |
| ИИС | yyy-yyy | ИИС | 500 000,00 | 50% |
| **ОБЩИЙ КАПИТАЛ** | | | **1 000 000,00** | **100%** |

### Листы по счетам

Для каждого счёта создаётся отдельный лист с информацией о позициях:

| Тикер | Название | Тип | Количество | Лотов | Валюта | Ср. цена покупки | Текущая цена | Ср. стоимость | Рын. стоимость | Доля от счета, % | Доля от капитала, % |
|-------|----------|-----|------------|-------|--------|------------------|--------------|---------------|----------------|-------------------|---------------------|
| SBER | Сбербанк | Акция | 100 | 10 | RUB | 250.00 | 270.00 | 25 000 | 27 000 | 5.4% | 2.7% |
| ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... |

### Описание колонок

| Колонка | Описание |
|---------|----------|
| Тикер | Биржевой тикер инструмента |
| Название | Полное название инструмента |
| Тип | Тип инструмента (Акция, Облигация, ETF, Валюта, Фьючерс) |
| Количество | Количество единиц инструмента |
| Лотов | Количество лотов |
| Валюта | Валюта инструмента |
| Ср. цена покупки | Средняя цена покупки единицы |
| Текущая цена | Текущая рыночная цена |
| Ср. стоимость | Средняя стоимость позиции в портфеле |
| Рын. стоимость | Текущая рыночная стоимость позиции |
| Доля от счета, % | Доля позиции в стоимости счёта |
| Доля от капитала, % | Доля позиции в общем капитале |

## Устранение неполадок

### Ошибка "Не установлен пакет openpyxl"

```bash
pip install openpyxl
```

### Ошибка "Не установлен SDK Т-Инвестиций"

```bash
pip install t-tech-investments --index-url https://opensource.tbank.ru/api/v4/projects/238/packages/pypi/simple
```

### Ошибка "ModuleNotFoundError: No module named 't_tech'"

Убедитесь, что используете правильный пакет:
```bash
pip uninstall tinkoff-investments -y  # если установлен старый пакет
pip install t-tech-investments --index-url https://opensource.tbank.ru/api/v4/projects/238/packages/pypi/simple
```

### Ошибка авторизации

- Проверьте правильность токена
- Убедитесь, что токен активен
- Проверьте права доступа токена

### Пустой портфель

- Убедитесь, что на счетах есть позиции
- Проверьте статус счетов (должны быть активными)

## Технические детали

### Используемые библиотеки

- **t-tech-investments** — Официальный Python SDK для T-Invest API
- **openpyxl** — Библиотека для работы с Excel файлами

### API методы

Скрипт использует следующие методы API:
- `users.get_accounts()` — Получение списка счетов
- `operations.get_portfolio()` — Получение портфеля по счёту
- `instruments.get_instrument()` — Получение информации об инструменте
- `market_data.get_last_prices()` — Получение текущих цен
